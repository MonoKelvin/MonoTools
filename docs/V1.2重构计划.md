# 项目重构与优化任务说明（遵循/karpathy-guidelines）

## 辅助工具使用规范
在执行以下重构与优化任务过程中，必须使用以下指定的mcp工具：
1. /exa-fetch：用于搜索相关技术实现方案、设计模式及最佳实践
2. /context7-mcp：获取最新的技术文档、开发标准和行业前沿开发方式
3. /sequential-thinking：应用结构化顺序思考方法，确保设计决策和实现步骤的逻辑性与有序性
4. /supermemory：记忆并检索项目相关知识、历史决策和已有解决方案，避免重复劳动和已知错误
5. /21st：搜索并获取符合现代审美标准的UI设计方案、组件设计灵感，确保设计简约美观

## 软件架构与性能优化
1. **项目架构分析**：
   - 对整个项目进行全面扫描，生成详细的架构文档，包括模块划分、依赖关系、数据流图
   - 识别当前架构中的性能瓶颈、耦合点和可优化区域，形成书面分析报告

2. **搜索引擎框架优化**：
   - 性能目标：达到与Everything产品相当的搜索响应速度和内存占用指标
   - 解决当前存在的关键问题：
     * 搜索性能缓慢问题（需提供性能基准测试数据及优化后的对比数据）
     * 数据库文件体积过大问题（制定数据压缩与清理策略）
     * 内存占用过高问题（优化内存管理机制，减少不必要的内存分配）
     * 索引内容缺失问题（完善索引规则，确保全覆盖）
   - 提供优化方案文档，包含技术选型、实现思路及预期性能提升

3. **代码设计优化**：
   - 实施模块化设计原则，提升代码可维护性
   - 降低系统耦合度，明确模块间接口定义
   - 优化代码组织结构，遵循单一职责原则
   - 完善错误处理机制和日志系统
   - 制定代码规范文档并应用于项目

4. **软件检索功能优化**：
   - 确保准确、全面地检索以下类型软件：
     * 用户安装程序
     * 系统程序
     * Windows特有UWP程序
   - 为每个软件获取完整详细信息：
     * 正确的软件名称
     * 应用图标（多种分辨率）
     * 安装路径
     * 版本信息
     * 关联文件类型
   - 处理快捷方式解析：
     * 准确获取快捷方式对应的真实程序路径
     * 提取真实程序的完整信息而非快捷方式本身信息
   - 实现检索结果缓存机制，提升重复检索效率

5. **启动性能优化**：
   - 解决启动后界面显示延迟问题：
     * 实现界面优先显示策略，采用骨架屏或加载状态提示
     * 将程序、文件识别等耗时操作改为后台异步处理
   - 实现流式数据加载：
     * 采用增量加载机制，获取到部分数据后立即显示
     * 实现数据加载进度指示
   - 修复界面阻塞bug：
     * 确保加载过程中界面可正常操作
     * 保证窗口可拖动、最小化/最大化等基本窗口操作不受阻塞
   - 提供启动性能优化前后的对比数据（启动时间、界面响应时间）

## UI/UX优化
1. **界面设计优化**：
   - 以提升用户体验为核心目标，确保界面简洁、直观、美观
   - 参考Raycast界面设计规范进行布局和交互设计（配色方案除外）
   - 优化信息层级，突出核心功能，减少认知负担
   - 确保界面响应迅速，操作反馈及时

2. **控件与组件优化**：
   - 统一控件样式，确保符合软件整体设计语言
   - 实现流畅的动画过渡效果和交互反馈：
     * 按钮点击反馈
     * 页面切换过渡
     * 加载状态动画
   - 适当应用视觉增强效果：
     * 合理使用高斯模糊背景
     * 添加适度的阴影和深度效果
     * 确保特效不影响性能和可用性

3. **主题系统实现**：
   - 开发完整的主题管理模块，支持一键切换主题功能
   - 代码实现要求：
     * 全面使用CSS变量定义样式属性，避免硬编码颜色、尺寸等
     * 采用类名机制实现主题切换
     * 设计主题接口，确保后续添加新主题的便捷性
   - 主题应包含但不限于：亮色主题、暗色主题、高对比度主题

4. **UI组件库与资源规范**：
   - 统一使用PrimeVue组件库作为基础UI组件
   - 通过封装以"Mt"为前缀的自定义组件实现统一风格
   - 图标资源使用规范：
     * 优先使用Lucide图标库
     * 辅助使用LobeHub-Icon图标库
     * 如必须使用自定义图标，需将SVG文件统一管理在资源目录中
   - 建立组件文档，包含使用示例和API说明

## 验收标准
1. 提供优化前后的性能对比报告
2. 提交完整的架构文档和设计规范
3. 确保所有功能模块通过单元测试和集成测试
4. UI设计符合现代审美标准且用户体验得到显著提升
5. 代码质量达到行业最佳实践水平，可维护性显著提高
